# Openhall

AI-generated 3D galleries that artists actually own. Upload up to 10 artworks, describe your space in natural language, and Openhall uses IBM watsonx.ai to produce a walkable 3D exhibition you can export and self-host anywhere — no subscription, no platform lock-in.

> Built with IBM Bob. Powered by watsonx. Owned by artists.

**Mobile note:** Free-walk mode (WASD + mouse look) requires pointer lock and is desktop-only by design. Touch devices are directed to guided tour mode automatically. A virtual joystick is out of MVP scope.

## Status
